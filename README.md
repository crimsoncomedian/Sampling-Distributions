# Sampling Distributions

An interactive simulation for exploring sampling distributions. Take a sample from a population, compute a statistic, and repeat thousands of times to see the statistic's sampling distribution build up.

- Choose or draw the population (normal, uniform, skewed, bimodal, or your own shape)
- Statistics: mean, median, standard deviation, variance (÷N and ÷N−1), mean absolute deviation, range
- Sample sizes 2 to 25, with an optional second panel to compare two sample sizes
- Fitted normal curve and CLT prediction overlays; hover over dots and bars to read exact values

Runs entirely in the browser. No data is collected.
